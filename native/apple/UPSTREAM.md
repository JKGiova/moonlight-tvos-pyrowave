# Apple decoder provenance

The pristine PyroWave dependency is MIT, copyright 2026 Hans-Kristian Arntzen,
pinned at `186f0393b77f7755953b5ecde994bb1cec2e4155`.

`shaders/wavelet_dequant_apple5.metal` derives from that pin's
`metal/shaders/wavelet_dequant.metal`. Local modifications replace SIMD prefix
sums and shuffles with a 128-thread, two-level threadgroup prefix scan. Packet
layout, coefficient order, quantization, sign order and output coordinates are
preserved. The missing-block exit remains uniform before all barriers.
`PyroWaveApple5Source.h` embeds this source verbatim and is regenerated by
`tools/embed_apple5_shader.py`; CI rejects a different embedded shader.

`integration/patches/pyrowave-metal-apple5.patch` adds a decoder-only factory,
Apple5 capability probing, MSL 2.2 compilation for the portable path, pipeline
thread/shared-memory checks and backend identification. The original Apple7
device/encoder admission API stays intact. Encoder creation rejects the local
decoder-only device. `tools/prepare_metal.py` applies this patch to a generated
copy used by the real tvOS target and offline harness; no submodule is modified.
The upstream iDWT and precision selection remain unchanged.

GPL Moonlight application. This provenance document does not replace the
